# Examples

Real output from a run, with a synthetic post in place of anyone's actual save.

- `sample-note.md` — what one deep post becomes: frontmatter, extracted link,
  steps, key points, entities, verbatim snippets, and the `## Related` block
  that appears once other notes share entities with it.
- `sample-digest.md` — the weekly digest written to `vault/_digests/`. Paste it
  into any chat model as "here is what I saved this week".

Your own notes land in `vault/<category>/` and are never committed.
